# Project Studio Skill

Use the `project-studio` MCP tools when the user wants to kickstart a new project or maintain a consistent design system:

- **`open_project_studio`**: Opens the interactive 2-tab side pane (`Project Kickstart` and `UI Kit Preview`).
- **`scaffold_project`**: Creates a new project folder with starter code, `.gitignore`, `README.md`, `LICENSE`, and `AGENTS.md`.
- **`scan_design_tokens`**: Extracts CSS custom properties (`--*`) from an existing project.
- **`export_design_system`**: Writes `tokens.css` and `DESIGN_SYSTEM.md` into a target project directory.
